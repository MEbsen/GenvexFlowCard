## What's changed

- Added support for Genvex Connect 1.5.4 capabilities.
- Added generic entity mapping and configurable fan ranges, named speed options and separate RPM displays.
- Improved airflow and fan animations, preserving animation timelines and input focus during state updates. Reduced-motion preferences are respected.
- Added controls for narrow cards and improved provider discovery.
- Improved experimental Danfoss Air support, including stop/start and AUTO discovery for Run Mode/Demand entities.
- Reworked the shared ventilation model and added model, provider, animation and browser regression checks.

Existing `custom:genvex-flow-card` configurations remain supported. The download filename remains `genvex-flow-card.js`.

### Known limitation

Danfoss Air remains experimental. AUTO discovery is covered by automated tests, but confirmation on the originally affected Home Assistant installation is still pending. See [the tracking notes](https://github.com/MEbsen/GenvexFlowCard/blob/v1.1.2/docs/pending-auto.md).

### Installation

Update through HACS, or download `genvex-flow-card.js` below for manual installation. Reload the browser after updating.
